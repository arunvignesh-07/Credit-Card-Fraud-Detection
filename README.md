# Credit Card Protection

## Credit Card Fraud Detection

A Data Science and Visualization project focused on analyzing credit card transaction data to identify patterns associated with fraudulent transactions.

## Project Overview

Credit card fraud is a real-world problem involving a large number of financial transactions. This project analyzes transaction data using data science and visualization techniques to understand the characteristics of legitimate and fraudulent transactions.

## Dataset

- Dataset: Credit Card Fraud Detection
- Source: Kaggle
- Target Variable: Class
- Class 0: Legitimate transaction
- Class 1: Fraudulent transaction
